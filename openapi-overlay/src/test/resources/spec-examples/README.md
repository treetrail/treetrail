# Examples of the Overlay Specification

The examples of the Overlay Specification 1.1.0 and 1.2.0 (https://spec.openapis.org/overlay/), one directory each,
with an OpenAPI description before (`openapi.yaml`) and after (`output.yaml`) applying `overlay.yaml`.

Where the specification shows the description before and after (`traits`, `copy-*`, `reusable-action-overrides`),
the files are taken from it. For the other examples the specification shows only the overlay; the descriptions
were written for this test, and `output.yaml` is what the rules of the Action Object give.
